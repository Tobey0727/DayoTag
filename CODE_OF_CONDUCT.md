# 社区行为准则 / Code of Conduct

## 中文

DayoTag 的 Issue、Discussion 和 Pull Request 面向所有用户与贡献者。我们希望这里保持友好、专业和可参与。

### 我们期望

- 就事论事：讨论问题、复现步骤和改进方案，而不是评价个人。
- 尊重差异：不同的手机、使用习惯、技术水平和母语都值得同样的耐心。
- 保护隐私：不发布任何人的录音、转写、行程或身份信息——包括你自己的敏感数据。
- 诚实反馈：不夸大问题，也不隐瞒复现条件。

### 我们不接受

- 人身攻击、骚扰、歧视性言论或恶意揣测动机。
- 发布他人隐私信息，或诱导他人泄露 API Key、配对码等敏感凭据。
- 刷屏、广告、与项目无关的推广内容。
- 恶意提交（含攻击载荷的文件、误导性的"修复"等）。

### 执行

违反准则的内容可能被编辑、隐藏或删除；重复或严重违反者可能被限制参与。对处理结果有异议，或需要私下报告涉及个人的问题，请联系 `dayotag0728@gmail.com`。

安全漏洞请勿公开提交，参见 [SECURITY.md](SECURITY.md)。

## English

DayoTag's Issues, Discussions and Pull Requests are open to all users and contributors. We want this to remain a friendly, professional and welcoming place.

### We expect

- Focus on the matter at hand: discuss problems, reproduction steps and improvements — not people.
- Respect differences: different phones, habits, skill levels and native languages all deserve the same patience.
- Protect privacy: never post anyone's recordings, transcripts, whereabouts or identity — including your own sensitive data.
- Honest feedback: don't exaggerate problems, and don't hide reproduction conditions.

### We do not accept

- Personal attacks, harassment, discriminatory remarks or bad-faith assumptions about motives.
- Posting others' private information, or soliciting sensitive credentials such as API keys or pairing codes.
- Spam, advertising or promotion unrelated to the project.
- Malicious submissions (files with attack payloads, misleading "fixes", etc.).

### Enforcement

Content that violates this code may be edited, hidden or removed; repeated or serious violations may result in restricted participation. To appeal a decision or report a concern privately, contact `dayotag0728@gmail.com`.

Please do not report security vulnerabilities publicly — see [SECURITY.md](SECURITY.md).
