# DayoTag 产品白皮书

## 一句话定义

DayoTag 是一枚可长期佩戴的 24H AI 记忆配饰：它把一天里自然发生的声音和重要时刻，变成可回看、可追问、可继续行动，也可以戴出去的个人记忆。

## 愿景

让每个人低门槛拥有一套隐私可控、可长期佩戴、越用越懂自己的 AI 记忆系统。

这里的“懂”不是替用户判断人生，而是在需要时找回相关上下文，并允许用户确认、纠正和删除。

## 为什么要做

手机 App 通常只知道用户主动输入了什么；录音设备擅长记录，却常常停在转写和摘要；通用 AI 助手能对话，但并不在生活现场。

DayoTag 想把这三件事连起来：

1. 设备在现场低负担采集。
2. 手机接住数据并完成理解。
3. 记忆系统把碎片跨时间串起来。
4. Skill 将记忆变成用户真正需要的结果。
5. 圆形反射屏让结果重新回到可穿戴表达。

## 产品主线

### 听见

设备负责声音采集、本地存储和状态显示。手机不在身边时，内容先留在设备里。

### 理解

手机 App 接收音频和事件，调用用户选择的模型服务，生成转写、活动片段和结构化结果。

### 记住

当天内容进入 Today 和短期记忆；跨天仍然有价值的人、承诺、偏好和主题，才进入长期记忆候选。

### 行动

Agent 和 Skill 可以把记忆变成会议卡片、灵感、待办、承诺、每日回顾和后续问答。

### 戴出来

壁纸、身份头像、幸运色和其他圆形内容可以同步回设备屏幕，让 AI 硬件也成为日常表达的一部分。

## 谁会需要它

### 普通记录用户与知识工作者

想低负担留住会议、灵感、承诺和生活片段，不愿意每天手动整理录音。

### AI 硬件爱好者

想体验一条已经跑通的设备、App、模型、记忆和屏幕闭环。

### 年轻表达用户

希望 AI 硬件不是藏起来的录音器，而是一枚可以换壁纸、做身份表达、融入穿搭的电子吧唧。

## 当前已经跑通的能力

| 环节 | 当前能力 |
|---|---|
| 设备采集 | 本地录音、存储和状态显示 |
| 用户标记 | 通过设备交互标记重要时刻 |
| 手机同步 | 蓝牙绑定、认证、增量回传和进度处理 |
| 音频理解 | 转写、片段整理和结构化结果 |
| Today | 多种内置 Skill 卡片 |
| Memory | 按日期回看、搜索和历史追问 |
| Agent | 基于授权记忆问答并调用 Skill |
| 可穿戴表达 | 壁纸、身份内容和圆形卡片同步 |
| 设备维护 | App 内 OTA 和异常恢复链路 |

## 设计原则

### 隐私先于功能

原始音频先保存在设备，再通过蓝牙直接进入用户手机。DayoTag 不建设音频中转服务器，也不提供云端音频存储；用户可以选择本地 ASR，让语音转写留在手机。使用云端模型时，由用户主动选择服务商并配置自己的 API Key。

### 重要结论尽量保留来源

模型输出应尽量能回到日期、音频片段或相关卡片，方便核对和纠正。

### 不把用户变成效率指标

产品关注值得留下的事实、想法、关系和情绪线索，不用单一分数评价一个人的一天。

### 硬件安静，结果有表达

设备本身尽量少打扰；真正有价值的结果进入 App，需要时再同步回屏幕。

### 能力有边界

声纹注册与删除由用户显式操作；情绪、关系类结果只来源于用户已授权处理的录音内容，且始终可以回看、纠正和删除。模型结果不替代医疗、心理、法律或其他专业判断。

## 当前边界

- 不保证模型输出完全准确。
- 不支持 iOS 安装包。
- 不建设统一的原始音频中转服务器。
- 本地 ASR 可以将语音转写留在手机；更完整的本地模型能力以具体 Release 支持情况为准。
- 长时间运行、不同手机后台策略和复杂生活音频仍需持续优化。
