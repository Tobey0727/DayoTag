# DayoTag 公开发布范围

## 仓库定位

这是 DayoTag 的公开下载与用户文档仓库，主要目标是让用户快速找到可安装 APK、设备固件、使用说明和正式反馈入口。

## GitHub 提供的内容

- Android APK（内置对应版本设备固件的 OTA 包，App 内直接执行固件升级）。
- 设备串口完整烧录包（首次写入与故障恢复用，含固件全部分区）。
- 每个发布版本的 SHA-256。
- Release Notes、已知问题和升级说明。
- 与当前二进制对应的第三方许可证和 NOTICE。
- 安装、配对、功能、隐私和故障排查文档。
- 产品白皮书和公开演示素材。
- 嘉立创硬件项目的统一跳转入口。

## 安全与发布底线

Release 只包含可安全分发且权属明确的文件。签名私钥、Keystore、证书私钥、生产凭据、模型 API Key、服务账号、内部测试数据，以及未明确取得授权的第三方素材和供应商文件，均不得进入仓库或 Release。

## GitHub 与嘉立创的分工

| 平台 | 主要内容 |
|---|---|
| GitHub | APK、固件、版本记录、使用文档、Issue |
| 嘉立创开源硬件平台 | 原理图、BOM、PCB、结构、装配和硬件复刻资料 |

GitHub README 不重复展开整套硬件资料，只保留设备简介和嘉立创正式链接。

## 二进制发布原则

- APK 和固件只通过 GitHub Releases 发布，不提交到普通 Git 历史。
- 每个二进制都要带版本号、目标硬件、发布日期和 SHA-256。
- 每个 Release 都要附带与最终二进制一致的第三方组件、许可证和 NOTICE。
- APK 需要明确 Android 最低版本和签名信息。
- OTA 包随 APK 内置，版本与 APK 绑定；串口完整烧录包需标明目标硬件版本。
- 未经真机验证的固件只能标记为 Pre-release，不能作为 Latest 稳定版本。
- Release Notes 必须列出已知问题和回退方式。
