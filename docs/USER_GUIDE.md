# DayoTag App 用户使用指南

这份文档面向首次下载 DayoTag APK 的用户，帮助你完成安装、模型配置、设备配对、同步和日常使用。

## 1. 使用前准备

你需要：

- 一台 DayoTag 设备。
- Android 7.0 或更高版本的手机。
- 开启手机蓝牙。
- 足够的手机存储空间。
- 如果使用云端模型：需先获取API Key。
  
  火山ASRkey获取方式（建议填写提升效果）：https://docs.volcengine.com/docs/6561/2485392
  
  豆包大模型key获取地址：https://ark.volcengine.com/overview
  
  MiMo大模型key获取地址：https://mimo.mi.com/docs/zh-CN/quick-start

  Deepseek大模型key获取地址：https://api-docs.deepseek.com/zh-cn/

当前没有 iOS 安装包。

## 2. 下载与校验

1. 打开仓库的 [Releases](https://github.com/Tobey0727/DayoTag/releases)。
2. 下载最新的 `DayoTag-Android-*.apk`。

macOS / Linux：

```sh
shasum -a 256 DayoTag-Android-*.apk
```

Windows PowerShell：

```powershell
Get-FileHash .\DayoTag-Android-*.apk -Algorithm SHA256
```

如果校验值不同，请删除文件并从官方 Release 重新下载。

## 3. 安装 APK

1. 在手机文件管理器中打开 APK。
2. 如果系统拦截安装，为当前浏览器或文件管理器临时开启“允许安装未知应用”。
3. 完成安装后，可以关闭该权限。
4. 首次启动时按提示授予必要权限。

### 权限用途

| 权限 | 用途 |
|---|---|
| 附近设备 / 蓝牙 | 发现、绑定并同步 DayoTag |
| 通知 | 显示后台同步、处理和设备状态 |
| 麦克风 | App 内语音输入等需要录音的交互 |
| 后台运行 | 保持设备连接、恢复同步和补跑任务 |
| 网络 | 调用用户选择的模型 API、检查更新 |

不同 Android 版本显示的权限名称可能不同。拒绝蓝牙相关权限会导致设备无法连接；其他权限可以根据实际使用决定。

## 4. 首次配置模型

安装包不内置可供所有人使用的 API Key。

1. 打开 App 设置。
2. 选择要使用的模型服务。
3. 填写自己的 API Key、模型名称和服务地址。
4. 保存后先做一次简短测试。

如果模型调用失败，请依次检查：

- API Key 是否正确、是否已过期。
- 账号是否有可用额度。
- 模型名称和接口地址是否匹配。
- 当前网络是否能访问所选服务。
- 服务商是否支持 App 当前使用的音频或对话接口。

使用云端模型前，请阅读对应服务商的数据与隐私政策。

## 5. 绑定 DayoTag

1. 打开手机蓝牙，并让设备保持开机。
2. 进入 App 的设备页面。
3. 点击搜索或添加设备。
4. 选择附近的 DayoTag。
5. 按设备屏幕和 App 提示完成配对码确认。
6. 绑定成功后，等待设备状态和固件版本显示。

### 搜索不到设备

- 确认 DayoTag 已开机且不在其他手机的连接状态中。
- 关闭再开启手机蓝牙。
- 确认 App 已获得“附近设备”权限。
- 将设备靠近手机后重新搜索。
- Android 11 及更早版本如果仍无法发现设备，可检查系统定位权限。

不要通过系统蓝牙设置页直接完成全部绑定流程；优先从 DayoTag App 内发起。

## 6. 日常使用

### 设备记录

设备会先把音频写入本地存储。即使手机暂时不在身边，已经产生的内容也不会依赖手机实时在线。

遇到值得单独留下的想法或事项，单击一次设备按键进入手动速记：设备屏幕外圈亮起表示正在速记，此时说的话会记录为一段独立内容，同步后生成对应的速记卡片。再按一下随时结束，或到设置的速记时长后自动结束。

### 同步到手机

手机重新靠近并连接设备后，App 会读取尚未同步的内容并增量接收。同步期间：

- 尽量保持蓝牙开启。
- 大文件传输时不要频繁强退 App。
- 如果系统限制后台运行，请允许 DayoTag 后台活动。
- 同步异常时先重新连接，不要急于删除设备数据。

### 生成 Today 卡片

音频同步并处理后，Today 页面会展示已经生成的结果，例如：

- 每日回顾。
- 会议卡片。
- 灵感与金句。
- 待办和承诺。
- 今日身份、幸运色和其他 Skill 卡片。

模型输出可能出错。重要待办、人物、时间和事实需要由用户确认。

### 查看 Memory

进入 Memory 后可以：

- 按日期查看历史内容。
- 打开当天的转写和卡片。
- 搜索相关记忆。
- 向全时记忆 Agent 追问过去发生的事。

如果回答不准确，应回到来源内容核对，不要把模型生成结果当作唯一事实。

### 使用 Agent 和 Skill

Agent 会根据当前问题读取所需的卡片、记忆和上下文，并调用已安装的 Skill。你可以让它：

- 继续整理某段会议或灵感。
- 查看或修改待办状态。
- 生成新的卡片结果。
- 基于历史内容回答问题。

不同 Skill 的权限和输出不同。涉及隐私内容时，请先确认读取范围。

### 同步壁纸到设备

1. 在 App 中打开支持同步的壁纸或圆形卡片。
2. 选择同步到设备。
3. 保持 DayoTag 已连接。
4. 等待 App 和设备显示同步完成。

同步失败时，先确认设备连接稳定，再重试；不要连续快速点击。

## 7. 固件 OTA

普通用户优先通过 App 执行 OTA：

1. 确认 DayoTag 已完成绑定和认证。
2. 在设备或固件更新页面读取当前版本。
3. 确认目标固件适用于当前硬件版本。
4. 保持设备电量充足、手机蓝牙稳定。
5. 开始 OTA 后等待设备安装并重新连接。
6. 更新完成后再次读取固件版本。

“传输完成”不等于“安装完成”。请以设备重新启动、重新连接和版本读取结果为准。

串口完整烧录会涉及分区文件、工具版本和设备数据，主要用于首次写入或故障恢复。需要自行 DIY 或手动恢复时，请先阅读[固件串口烧录指南](FIRMWARE_FLASHING.md)。当前 DayoTag 的 Type-C 只引出 UART 串口，不支持用普通 Type-C 线直连电脑烧录，必须使用外置 3.3V USB-to-UART 转接器。

## 8. 常见问题

### 卡片一直没有生成

检查音频是否已同步、网络是否可用、API Key 是否有效、账号是否有额度，以及所选模型是否支持当前请求。

### App 退到后台后不再同步

允许通知和后台运行，将 DayoTag 加入系统的电池优化白名单。不同品牌手机的后台策略差异很大。

### 设备连接后反复断开

先关闭其他已绑定手机的蓝牙，重启手机蓝牙，再从 App 内重新连接。仍然失败时记录手机型号、Android 版本、App 版本、固件版本和发生时间。

### 更新 APK 会不会清空数据

同一包名和同一签名的版本通常可以覆盖安装并保留数据，但正式发布版签名发生变化时可能无法直接覆盖。更新前请先阅读对应 Release 说明并备份重要内容。

### 可以只用本地模型吗

产品支持用户选择模型与处理方式；实际支持范围以 App 设置页和对应 Release 说明为准。

## 9. 反馈问题时请提供

- 手机品牌和型号。
- Android 版本。
- DayoTag App 版本。
- 设备固件版本。
- 问题发生时间和操作步骤。
- 是否可以稳定复现。
- 已脱敏的截图或日志。

请不要公开 API Key、原始录音、完整转写、配对码、设备唯一标识或其他人的隐私信息。
